# 账号资料库的前台自动同步

状态：2026-10-05 独立账号服务已部署，开发版 Linux/Pixel 同账号自动同步通过，公开 0.18.0 尚未更新。仅用于账号 `/v2/vault`，旧个人令牌 `/v1/vault` 保持手动同步。当前交付见 [账号体验与部署报告](account-center-deployment-2026-10-05.md)，隔离边界见 [账号与同步](accounts-and-sync.md)。

## 行为

- 账号资料库默认自动同步，包括无冲突的首次连接。不自动导入原本机资料；旧个人令牌连接仍保持手动方式。已明确关闭自动同步的账号保留原选择。
- 「我的账号」与「偏好设置」独立。普通账号界面只呈现登录、设备与同步状态；服务地址、设备名称及手动同步诊断位于收起的高级区域。
- 前台恢复、联网事件、任务/目标保存与保存队列完成会安排检查。连续保存合并为约 4 秒后的检查；无变化时约每 60 秒检查。
- 下载/应用之前要求至少 8 秒没有键盘、触控或输入活动，全部数据成功读取、保存完成，且没有编辑器、设置、导航遮罩、备份、目标保存或日期弹层。
- 目前接收数据仍重载全部业务组件，保留当前总览/今天/全部计划/完成记录/日历页面和独立的笔记草稿。其他工作区允许检查，但等待返回这些安全页面后才提交；不会在对话、AI 生成或生活计划编辑中突然刷新。此限制尚未通过细粒度组件更新替代。
- 仅上传、没有本机记录变化时不重载，保存锁正常释放；收到更改时保持锁直到重载，防止旧 React 状态回写覆盖导入资料。
- 离线不删除数据，网络失败以 5 秒起步、指数退避并增加抖动，上限约 5 分钟；本机新保存不能绕过退避期限。过期预览/并发 revision 冲突先重新检查。
- 不同字段的更改自动合并。同一内容无法可靠合并时，账号页按业务内容逐条询问保留哪份，保留安全副本，不显示 revision、令牌或同步协议。会话失效只要求重新登录，成功后恢复；完整性异常仍暂停并需要维护者核实。
- 账号页展示「已同步 / 离线保存中 / 需要重新登录 / 有内容需要确认」，前台顶栏在暂停时显示账号入口。自动和手动预览分别存储，关闭/取消只释放匹配预览。收到更改后保留载入锁，载入失败有全局重试入口，不解锁过期界面。

Android 仅承诺应用处于前台时的上述行为，没有新增后台常驻服务、WorkManager、云推送或系统挂起后的持续同步。同步范围仍是已保存任务、笔记、目标与对话，不扩展到生活模块、API 密钥、通知设置或草稿。

## 防护

原生再次验证不可变资料库身份与待重启状态；自动预览和提交复用手动同步的三方合并、资料库身份/历史校验、安全副本及 SQLite 快照事务。网络、鉴权、过期请求与完整性错误分别返回类型，不以错误文本猜测是否应该重试。

自动设置是资料库目录下的 `automatic-sync.json`，原子写入、权限 600，校验版本、文件大小和所属资料库，拒绝符号链接或外来/未来配置。未启用、暂停、手动预览占用、资料库将切换或预览不匹配时不得自动提交。无效预览 ID 不会清除另一份有效预览。
