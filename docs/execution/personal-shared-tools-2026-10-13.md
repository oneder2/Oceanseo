# Linux 个人版 0.19.3：共享工具与即时切换

用户将工作区规则调整为：工作区管理工具入口和视觉风格，同一工具在各工作区共享资料。本轮还处理切换时的窗口透明闪动、侧栏滚动条与工具操作菜单。

## 实现

- 同一资料库中的工具使用同一份数据；不同账号资料库保持原有边界。工作区独立管理工具入口，删除某个入口不会删除共享资料或其他工作区的入口。
- 原生状态、工作观察、地图设置和主机凭据统一读取共享存储。沿用数据库 schema，工作区注册文档继续使用原有格式；备份新增可选 `sharedTools` 标记，兼容旧备份。
- 旧资料先在临时数据库校验合并结果，再保存迁移前快照。数组按记录身份合并，同一身份选择较新的修订；原工作区快照保留。旧单张拼豆图纸转为作品，使用稳定身份避免迁移重试时重复生成。相同项目路径的工作观察历史统一项目身份；主机凭据整体保留，避免混合不同来源的地址与令牌。
- 新版备份恢复后以共享资料为准，不会再次合并旧工作区快照，避免复活已删除内容。旧版备份恢复后仍可执行一次迁移。
- 切换工作区和添加、删除、修改工具原先调用 `window.location.reload()`。由于原生窗口与页面背景支持透明，重载期间页面卸载导致整个窗口瞬时透出桌面。现在等待写入后直接发布工作区状态，保持 WebView 和界面根节点；根面板提供不透明背景。显示范围、页面回退和视觉风格同步更新。
- 生活资料与主机事件的显示缓存随工具入口变化刷新，添加工具后立即可见共享内容；页面回退在绘制前处理。
- 侧栏为滚动条预留独立区域，三点按钮与其保持间距。操作菜单通过 portal 悬浮显示，包含「属性」和「删除工具」；支持方向键、Esc、外部点击关闭，Esc 返回触发按钮。属性显示当前工作区、共享范围及已添加到的工作区。
