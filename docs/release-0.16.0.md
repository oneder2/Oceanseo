# 0.16.0 · 个人跨设备同步内测

日期：2026-09-29。用户反馈第一阶段初步验收未发现问题，本轮推进第二阶段。版本 0.16.0，Android versionCode 1600。服务器仍在选购，本轮不部署公网、不启动 GWorkspace 等下游任务、不修改生态 contracts。

## 本次交付

- Linux / Android 共用设置页同步入口：地址与令牌配置、最近同步状态、待传记录数、更改与删除预览、冲突双方对照、确认同步、断开连接及同步前副本导出。
- 同步任务、笔记、日期、完成状态，以及整组目标和已保存对话／理解图／交付清单。任务非重叠字段可合并；同字段、删除与编辑、同时修改的目标对话需要显式选择。
- SQLite 中保存共同基线和删除墓碑，离线修改保留；服务端 revision 比较、客户端快照比较、合并与基线的原子提交，避免静默丢失更新。任务仍使用原来 1.0.0 公共契约，没有更改外部接口。
- Python 标准库 + SQLite 的个人同步服务，独立 Bearer 令牌、私有文件权限、请求体限制、拒绝丢弃历史 ID。提供 systemd / Caddy 配置示例和在线 SQLite 备份脚本。
- 同步前创建包含两端版本的本机安全副本；可以从设置导出，再通过既有备份入口恢复本机备份部分。同步凭据不进入业务备份，Android 使用 Keystore 加密。

详细规则、服务器规格建议与部署流程见 [跨设备同步说明](cross-device-sync.md)。

## 明确边界

当前是手动检查确认的个人私有内测同步，不是后台自动同步。生活模块、附件、多用户账号、设备级撤销、端到端加密和增量分页尚未实现。一个令牌只用于同一人的设备，不能多人共用。全量同步快照容量上限约 16 MiB；尚无公开并发容量承诺。

服务器地址、HTTPS 域名与实际部署待用户选购服务器后落实。长期发行签名归属及仓库外密钥备份仍待确定；本轮 APK 保持原有调试签名和 `.debug` 包名，不冒充正式商店签名包。已提供签名构建入口与本地 CI 定义，但没有触发远程 CI、推送仓库或公开发布。

下一步：部署私有 HTTPS 服务 → 用实际电脑与手机资料连续内测（先备份）→ 明确长期签名与密钥保管 → 生成小范围分发签名包并做升级／迁移验收。第二阶段尚未宣布全部完成。
