# 潮汐计划 0.9.0 验收报告

日期：2026-09-15。

## 交付内容

1. 人物档案：姓名、公历生日及派生年龄/属相/星座、关系、忌口、偏好、爱好、特长、健康与出行注意、私人备注；支持搜索、编辑、归档与恢复，稳定 ID 关联后续计划。
2. 训练计划：项目、组数、每组目标及单位、起始日、间隔天数和周期次数；Agent 优化草稿；日历映射；逐组实际记录、显式完成状态、到期完成率及 Agent 周期复盘。复盘持久化，记录变动后旧复盘失效。
3. 旅行计划：多人物画像、起终点、日期、人民币总预算、多类旅行目的与可自定义偏好；Agent 生成可编辑的住宿/餐饮/游览建议，预算与遗漏检查；日历联动；高德地点候选确认、当天步行/驾车路线、可拖动缩放地图。
4. 基础设施：生活数据纳入原有 SQLite app_state 与 JSON 备份；Agent 共用现有 AI 配置；地图 Key 后端独立保存，Linux 0600 权限、原子写入，公开摘要不暴露完整密钥。

详见 [业务及使用规范](life-planning.md)。范围限于 Oceanseo，未启动下游项目任务或更改 contracts。

## 设计与实现

使用既有 React / TypeScript / Tauri，加上按需加载的 Leaflet。通过 ui-design 技能组织“人物资料 → 计划 → 记录”的信息层级：人物列表与编辑面板、训练日期条与逐组输入、旅行条件栏与地图日程。沿用青灰信息区与珊瑚色主按钮，未使用外部组件灵感素材。地图包单独加载，主 JS 产物约 417 kB，地图约 151 kB（均为压缩前文件大小），生产构建无超大主包警告。

新模块主要在 `src/life/`，包含模型、校验、三个页面、Agent 生命周期、地图调用与配置。后端新增 `planning.rs`、`maps.rs`；扩展 `App.tsx`、`CalendarView.tsx`、`WorkspaceNav.tsx`、`appDataStore.ts` 和后端 app_state 键白名单。

- 前端 `npm test`：27/27 通过。其中新增 8 项覆盖年龄与农历春节边界、夏令时日历周期、到期统计、画像字段隔离、数据校验、行程范围与费用、AI 输出过滤、地图坐标转换及日程遗漏检查。
- Rust 单元测试：原有及新增共 29 项通过（先执行 28 项全量，再执行新增备份/重启专项 1 项）。新增覆盖地图 Key 持久化/权限/隐藏与清除、坐标校验、封闭输出 Schema 和生活数据备份恢复。
- `cargo clippy --lib -- -D warnings` 通过。
- TypeScript、Vite 生产构建、Tauri release 和 Debian 打包通过；`git diff --check` 通过。
- Playwright 实际界面操作：录入人物、应用内生日选择器跨年跳转、农历属相显示；手动创建训练周期、逐组录入、缺失实际量拦截、显式完成、日历跳转；自定义旅行目的、行程保存及重载恢复；地图 Key 配置入口。
- 受控 IPC 测试：用固定 Agent 响应验证训练复盘落库、旅行草稿不提前保存、画像不包含生日原文/私人备注；用固定地图响应验证候选选择、路线持久化、地址变更清除旧坐标和路线；延迟 Agent 响应验证取消后的迟到结果不覆盖草稿。上述服务响应为测试替身，不是真实付费服务调用。
- 可视化检查：1240×790、700×800、390×844；旅行页面无横向溢出。地图在浏览器中实际加载 OpenStreetMap 在线底图。截图中的路线来自受控测试数据，仅用于验证绘制流程，不作为实际导航路线。
- 独立生产预览：默认只选择周期内训练日，未来训练禁用完成、历史日完成记录和日历跳转正确、设置显示 0.9.0；损坏本地数据保留原始值且显示错误，未被空数据覆盖。控制台 0 错误、0 警告。
- 本机截图：`output/playwright/life-people.png`、`life-fitness.png`、`life-travel.png`、`life-travel-narrow.png`、`life-travel-mobile.png`、`life-map-settings.png`。测试数据均在隔离浏览器环境中，未改动用户真实人物/计划数据。

未实测用户实际 AI 服务商的模型权限、生成质量或高德付费服务权限；需要配置后实际验证。未覆盖安装现有应用，未自动化原生 Linux 窗口/文件对话框。当前 Agent 为主动触发的受约束规划流程，不是无人值守后台任务；训练周期为固定日间隔，同一周期重复项目模板。地图以国内地点及步行/驾车为主，不提供海外完整检索、实时房价、订票、跨城公交班次或实时导航。

