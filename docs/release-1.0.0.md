# Oceanseo 1.0.0 — Linux 个人版

Oceanseo 首个公开的开源个人版发行。项目原创源码采用 MIT；字体、拼豆色卡和依赖继续遵守各自授权，详见根目录的 `LICENSE` 和 `THIRD_PARTY_NOTICES.md`。

## 工作区与工具

- 默认仅有一个不可删除的主工作区，包含天气、时间、日历和总体待办。其他工作区可创建、重命名、删除并选择视觉风格，名称和工具组合自由决定。
- 同一工具在工作区之间共享资料，工作区分别管理自己的入口。待办共用一份资料，必须归属一个工作区或「待定」，所属工作区优先展示。
- 工具三点菜单提供属性与删除。删除只移除当前工作区入口，重新添加后可继续使用资料。侧栏宽度和窗口大小可调节，滚动条不会遮挡工具按钮。
- 切换工作区及增删工具直接更新界面，避免整页重载导致的透明闪动。F11/窗口扩展按钮在桌面工作区域最大化，保留系统面板。
- 保留采购、生活与旅行、人物、训练、目标、工作观察、主机和计划工具。拼豆编辑、作品管理和拼放进度统一为一个模块。

## 安装与升级

发行附件提供 Linux amd64 DEB 和 SHA-256 校验文件。下载后在所在目录执行：

```bash
sha256sum -c SHA256SUMS
sudo apt install ./Tideplan_1.0.0_amd64.deb
```

应用菜单名称为 Oceanseo，包名保留 `tideplan`，桌面身份保留 `com.tideplan.desktop`，以兼容历史安装和资料。升级前可在应用内导出备份；旧工作区工具资料首次启动时合并，迁移前快照和原工作区存储保留。历史独立拼豆图纸保留为作品。

源码构建使用 Node.js 22、Rust stable，以及 WebKitGTK 4.1、Ayatana AppIndicator、librsvg 和 libxdo 的开发依赖：

```bash
npm ci
npm test
npm run release:linux
npm run cleanup
```

## 验收范围

本次发行针对 Linux amd64。本机环境为 Linux Mint 22.1。121 项前端测试、134 项 Rust 回归测试、Rust 格式及严格 Clippy 检查通过；账号服务 53 项、同步服务 7 项、备份审计 8 项及备份提醒 4 项测试通过。生产构建和体积预算检查通过，浏览器验证了共享资料、工具移除与恢复、属性菜单、窄窗口按钮命中和连续切换。最终 DEB 解包后的程序通过真实 WebKit/GTK 窗口验证：从 0.19.2 隔离资料目录升级，旧采购、人物、图纸和地图设置保留并共享；工具删除只影响当前入口。连续操作保留同一页面和窗口尺寸；620 × 560 窗口下按钮边缘正常命中，菜单完整显示。包内 MIT、字体和色卡授权文件验证通过。

Android 仍独立保持 0.18.0，本次未附 Android、Windows 或 macOS 发行包。账号同步是可选功能；AI 和地图功能需要用户提供自己的配置。此次未修改线上域名、反向代理或部署服务，也未新增真实付费 AI/地图账号的验收结论。
