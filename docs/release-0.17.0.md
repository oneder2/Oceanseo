# 0.17.0 · 主机与服务内测

日期：2026-10-03。新增个人基础设施管理入口，版本 0.17.0，Android versionCode 1700。按 [四阶段计划](infrastructure-plan.md) 顺序实施；本轮未购买或部署服务器、未修改生态 contracts、未启动下游项目任务。

## 本次交付

入口为「个人项目 → 主机与服务」，手机从底部「工具」进入。主面板呈现待处理事项、不同币种的月均成本和可筛选主机卡片；右侧详情分为档案、服务、费用与期限、维护、监测，手机全宽显示。沿用海绿与纸面视觉、加强抽屉滚动和底部操作区，320 px 宽度可以使用。

- 档案：供应商官网/控制台/工单入口、规格/机房/连接信息、用途/环境/项目、订单来源及核实日期、服务部署信息。外部链接通过系统浏览器打开，SSH 只存凭据引用。
- 生命周期：首期与续费价、税费、原币月均成本、付款历史、保留月末锚点的账期推进、流量与重置记录、退款/取消/域名/证书等期限、备份与恢复验证、维护日志。期限进入日历和总览，待处理事项打开带来源的任务草稿；同来源不重复创建任务。
- 监测：用户指定健康端点的可用性、可选 Linux 只读资源采集器、时间与过期状态、CPU/内存/磁盘阈值、最近 120 条样本。采集器令牌与地址绑定，独立存储，不进入业务备份或 AI。
- AI：共享已有 AI 配置，订单文本/截图生成可编辑待确认档案；运行摘要发送前展示脱敏内容并要求同意。建议只打开任务草稿，用户确认后保存。既有助手增加默认关闭的主机摘要读取范围。

详细操作、采集器部署和数据边界见 [使用说明](infrastructure.md)。

## 当前边界

- 主机文档进入完整备份，尚未进入当前任务/目标的跨设备同步。
- 监测仅在应用运行且可见时进行，不承诺退出后的连续监控；网络字节是启动后网卡累计值，不是供应商账期流量。
- 桌面每日通知包含主机待处理数量；Android 仍使用现有通用每日系统提醒，不增加逐主机精确闹钟。
- 采集器需要用户在自有 Linux 服务器部署并配置 HTTPS；本轮提供代码与部署示例，没有远程安装。
- 周摘要由用户主动生成，没有定时付费 AI 调用；订单识别准确率和兼容服务商的图像支持仍需实际配置后验收。
- 不提供云厂商购买/重装/付款 API、SSH 执行、自动修复或多人权限管理。

下一步适合在服务器购入后录入真实订单、部署只读采集器，观察一个实际账期和几天采样，再评估主机档案跨设备同步及应用退出后的通知需求。
