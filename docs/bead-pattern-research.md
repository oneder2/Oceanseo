# 拼豆图纸：调研与本版设计

> 0.9.2 已更新色卡、采样和降噪实现。下面保留初版调研过程；当前行为以 [0.9.2 色卡与图像转换说明](bead-palettes-and-quality.md) 为准。

调研日期：2026-09-14。本报告区分公开资料、工程推论和仍需实测的行为假设；未进行用户访谈，不把工程选择描述为统计结论。

## 公开资料

- [Perler：U R My Valentine](https://perler.com/blogs/projects/u-r-my-valentine)：官方项目页提供 PDF 图纸和用色清单，说明按图案逐颗摆豆，并可把原尺寸图纸放在透明底板下。支持“定位准确、逐格可读、用色清楚”是制作流程的基本需求。官方图纸和素材没有复制进应用。
- [Color quantization](https://en.wikipedia.org/wiki/Color_quantization)：调色板生成与像素映射是两个步骤；Lab 空间距离更接近感知差异；聚类可减少用色，抖动通过交错像素模拟更多颜色。
- [Bilateral filter](https://en.wikipedia.org/wiki/Bilateral_filter)：结合空间和颜色差异的权重，可在平滑近似颜色时保留强边缘；平滑也可能造成阶梯色带，因此需要可控强度。

## 对高质量图纸的判断

图纸既是图像，也是一份可执行的手工作业说明。优先保留轮廓、识别性细节和大色块；坐标从左上角 (1,1) 开始，每五格加粗；格子内标识与用色表一致；透明空白不算豆。完整导出含尺寸、数量、颜色名称、HEX、每格编号和坐标，与屏幕当前平移、缩放无关。

推论：减少很相近的颜色和孤立杂点，可能减少找色、换色与数格负担；这不是已经验证的用户偏好。眼睛、高光也可能只占一格，所以不能直接删除所有小色块。拼接底板、按色施工、逐行施工和原尺寸打印各有不同需求，后续需要真实使用反馈。

## 实现策略

1. 原始像素模式：最近邻采样，无滤波、聚类、抖动或去杂色。尺寸相同时逐像素保留 RGB；alpha < 128 为空格，其他像素映射为不透明实体豆。支持最多 256 个原稿颜色，超出时要求改用照片转换。放大像素画可手动填回原始格数；带文字/网格的图纸截图不会自动去网格。
2. 照片模式：按目标网格平滑采样；保留宽高比，不足处透明留白。颜色上限 2–48，可选关闭、温和、较强去杂色。
3. 小范围双边平滑减少相似色噪声。五位 RGB 直方图构建加权样本，确定性远点初始化和最多十轮 Lab k-means 限制计算量；按近邻取样本代表色，合并感知距离很近的中心。
4. 不启用误差扩散抖动，避免为模拟连续色调引入大量交错色点。色带是有限颜色的明确取舍；增加颜色数或关闭去杂色可保留更多过渡。
5. 去杂色只替换八邻域中至少五个同色、原色邻居不超过一个且 Lab 色差低于阈值的点。保留强对比孤立细节；仍可能简化低对比细节，因此应用前必须预览，并支持撤销。
6. 转换在 Web Worker 中执行，可取消；主线程负责图片解码和缩放。输入文件限制 16 MB，解码后限制 1600 万像素，图纸上限 160×160，导出单格 28 或 36 px。解码前无法仅凭文件大小保证解码内存，极大压缩图片仍需先在外部缩小。
7. Canvas 只绘制当前视口可见单元，平移受边界约束；缩放以鼠标位置为中心，缩小时按间隔显示坐标，放大后显示每格编号。PNG 始终输出完整可读编号与用色清单，不含编辑按钮，也不是物理 1:1 打印模板。

## 色号与数据边界

B01 等编号是当前图纸内的稳定索引，不冒充 MARD、Hama 或 Perler 厂商色号。用户可以调整色值和名称以填写自己的实体豆色号；屏幕色不能保证实体豆匹配。当前保存一份图纸，切换工作区和重启后恢复，纳入本地数据备份。撤销最多二十步，退出页面后不保留撤销历史。

## 验证与后续

自动用例覆盖原色/透明/孤立细节保留、颜色上限、确定性、尺寸调整、损坏数据拒绝以及最大网格。合成图测试不能代替照片质量评估；后续应选取人像、动漫、宠物、风景各类用户授权素材，比较轮廓辨识、孤立点数、实际选色时间与用户偏好。

值得继续开发：可核验的厂商色卡和库存约束、按底板分块与 A4/PDF 原尺寸打印、逐行/按色进度标记、选区/填充/局部重新配色、图纸库及工程文件交换、背景移除与主体裁剪。优先级建议为实体色卡和分块打印，其次施工进度；先把“屏幕上好看”推进到“实际拼得顺手”。
