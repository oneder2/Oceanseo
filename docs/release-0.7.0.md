# 潮汐计划 0.7.0：拼豆编辑与操作体验

日期：2026-09-14。入口：个人项目 → 拼豆图纸。

## 已交付

1. **同色定位**：选色后，在色卡旁显示该色号全部豆的位置和数量；紫色表示选中色的位置，灰色表示其他豆。独立辅助视图可放大，主画布不变色，定位标记不参与 PNG 导出。选色或吸管不会自动切为画笔，提供「用 Bxx 绘制」明确入口。
2. **填充**：一键填充所有封闭空洞；区域填充工具替换点击处上下左右相连的同色区域。空心指透明空格，白色像素仍是白色豆子。与画布边缘连通的空白不自动填充；斜向接触不视为区域连通。
3. **加边**：使用当前豆色，沿外轮廓增加 1–8 层（包含斜角），保留原有豆与内孔。默认触边时自动扩展，超过 160×160 拒绝操作；关闭扩展时限于当前画布。扩展可能使原图案坐标整体平移。填充和加边均先预览、再确认，显示豆数变化，可撤销/重做。
4. **真实尺寸换算**：默认 5 mm，也可用 2.6 mm 或自定义 0.5–20 mm 豆距。分别显示画布大小和排除外围透明留白后的图案占用大小，PNG 同时标注。旧图纸兼容默认值，新豆距随图纸保存并进入现有 JSON 备份。
5. **图案边缘**：占用格与空白交界处绘制深浅双线，包含外轮廓和内孔。辅助线不改变原色或豆数；屏幕可关闭，PNG 保留辅助线及说明。
6. **UX**：缩小重复标题，把同色定位放在色卡旁，操作提示不推动主画布；补充豆色搜索、已用色筛选、当前工具与用色说明、较大文字和控件。预览及放大定位弹窗支持键盘焦点约束和 Esc 关闭，配合现有全屏模式使用。

## 设计与实现

继续使用既有 React / TypeScript / Canvas / Tauri 架构。沿用蓝灰画布和青色编辑工具，紫色虚线面板专门表示辅助定位；让实际图案和辅助视图有明确视觉区别。没有使用外部组件参考或新增图像素材。

主要文件：

- `src/BeadStudio.tsx`：工具集成、预览和交互。
- `src/beads/edit.ts`：四邻域填充、外部空白识别及八邻域外轮廓加厚。
- `src/beads/model.ts`：尺寸元数据、兼容验证和占用范围换算。
- `src/beads/ColorLocator.tsx`、`PhysicalSize.tsx`：定位图及尺寸设置。
- `src/beads/render.ts`、`studio.css`：边缘辅助线、导出尺寸信息与工作台布局。
- `tests/beads.test.ts`：算法、输入边界及兼容性回归检查。
