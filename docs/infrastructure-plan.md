# 主机与服务实施计划

目标：个人基础设施管家，回答“服务器为哪个项目提供什么、哪里需要关注、下一步做什么”。不修改生态 contracts、不启动下游项目，不购买或部署真实服务器。

## 顺序与验收

1. **档案基础**：个人项目导航入口；主机新增、编辑、归档、删除；供应商/控制台/工单、规格、地区、用途、环境、项目、连接信息及凭据引用；来源与核实日期；服务关联；SQLite 保存和备份校验。验收：重载保留、错误档案不覆盖、移动布局可操作。
2. **生命周期**：原币成本汇总、续费周期与付款历史、流量额度及重置记录、退款/取消/域名/证书/自定义期限；备份状态、恢复验证、维护日志；日历直达主机、创建带来源的维护任务，提醒进入现有日常提醒。验收：月底/闰年周期、不同货币不混加、归档过滤、重复任务防护、恢复保留关联。
3. **只读监测**：HTTP(S) 可用性检查，采集时间/来源/失效状态；可选 Linux 标准库采集器，通过 HTTPS + 独立令牌读取 CPU/内存/磁盘/启动后网络计数；本机前台定时检查、历史样本、阈值提示；令牌独立加密存储且不进入业务备份。验收：真实本机 HTTP、认证失败、超时/重定向/响应限制、陈旧样本不报健康。应用退出不承诺继续探测，不远程运行命令。
4. **AI 与收尾**：订单文本/截图识别为待确认档案；本地周摘要、共享 AI 配置生成结构化运行摘要与维护建议；逐项打开任务草稿，现有助手可按授权读取脱敏基础设施摘要。验收：不发送地址/凭据/私密日志、不虚构监测、不自动运维/付款、错误响应保留原数据；全套适度回归和构建。

## UI 设计

沿用潮汐海绿和纸面风格：深海 #244e52、海绿 #387d77、雾白 #f4f8f7、边界 #d5e2df、珊瑚 #bb604d；使用现有中文无衬线字体，数值等宽。主区域展示“待处理”清单与可筛选主机列表，右侧抽屉处理单机详情；详情页签为档案/服务/费用与期限/维护/监测。标志性元素为每台主机下的“服务 → 项目”关联行，表达真实用途而非装饰图表。手机抽屉全宽，表单两列降为一列。

## 边界

第一轮属于个人资源管理，不提供云厂商购买/退款/重装 API、SSH 终端、自动付款、自动修复或多用户权限平台。跨设备同步仍只覆盖原有核心任务/目标；主机档案通过完整备份迁移，不能宣称已经联网同步。机密仅保存凭据引用，采集器访问令牌使用单独安全存储。AI 使用用户主动选择的数据和既有配置，不增加定时付费调用。
