# 拼豆工作台：交互与业务规范

适用版本：0.8.0。范围为 Oceanseo 拼豆页面，不涉及生态契约或其他项目。

## 目标与布局

为导入、修改和照图摆豆提供长期可用的工作台。画布拥有剩余视口高度，页面整体不纵向滚动；属性面板独立滚动。层次从上到下为文档栏、绘图工具、面板入口、画布、状态栏。默认面板关闭，宽屏右侧停靠，窗口宽度不超过 1100px 时覆盖展示。

「专注画布」隐藏全局导航并收起属性面板；「退出专注」恢复导航。它与 F11 应用全屏独立。打开面板和改变窗口大小保持缩放及视口中心对应的网格位置；图纸格数变化或主动点击「适应画布」才重新适应。

视觉沿用 React/Tauri 桌面应用体系：蓝灰色画布 #e8eff2、浅色工具面 #f5f8f9、深蓝灰文字 #263b46、青色操作 #367c87、紫色定位 #7457b8。中文采用 Noto Sans CJK SC 字体栈，色号与坐标采用等宽字。识别特征是原色编辑画布与独立紫色定位图，避免把辅助标记误认成实物豆色。不添加装饰性动画，未使用外部组件灵感参考。

## 状态归属

| 状态 | 内容 | 保存与历史 |
| --- | --- | --- |
| 图纸文档 | 标题、宽高、色卡、格子、豆距 | 确认后自动保存；全部进入同一撤销历史 |
| 编辑会话 | 当前工具、选色、面板、搜索、镜头、辅助线、临时笔画、预览、撤销历史 | 内存；面板收起保留配置，离开页面后重置 |
| 异步作业 | 图片解码、Worker 转换、原图资源、导出 | 不保存；导入可取消，卸载释放资源 |

当前只持久化一份图纸。撤销历史最多 20 步，不跨页面重载保留。旧存储键 `tideplan.bead-pattern.v1` 和图纸 `version: 1` 不变；省略豆距的旧数据按 5mm 解释，继续纳入原有本机数据库与备份流程。

## 统一修改规则

所有修改通过 `documentReducer`。`commit` 提交一次修改；`propose` 冻结当前基线并提出预览；`apply` 把预览作为一次修改提交；`discard` 丢弃预览。`undo`、`redo` 按修改顺序移动历史。无变化操作不占历史且不清空重做；有效新修改清空重做分支；无效图纸拒绝进入文档。

预览期间拒绝底层修改和撤销，避免预览基线失效。批量修改必须同时显示前后图纸、数量变化与操作说明，用户应用后才影响文档。异步转换和导出期间锁定文档编辑，防止旧结果覆盖新状态。

| 操作 | 交互 | 提交边界 |
| --- | --- | --- |
| 拖动/缩放 | V、拖动；滚轮缩放，中键随时平移 | 仅修改视图 |
| 画笔/橡皮 | B/E，按下并拖动 | 抬起提交整笔；Escape、Ctrl+Z 或 pointercancel 丢弃当前笔画 |
| 选色/吸管 | 豆色面板或 I 点击有豆格 | 仅更新当前色，不隐式切工具 |
| 开始画当前色 | 点击「用 Bxx 绘制」 | 切换画笔并收起面板 |
| 区域填充 | G 点击四邻域相连同色区域 | 预览→应用，整次撤销 |
| 填充空心/加边 | 面板指定颜色、厚度、是否扩展 | 预览→应用；沿用既有算法与 160×160 上限 |
| 导入图片 | 选图→设置模式/尺寸→生成预览 | 预览→应用；继承当前豆距 |
| 调尺寸/新建 | 尺寸面板 | 预览→应用；裁切规则明确展示 |
| 标题/色名/色值 | 编辑字段 | 失焦提交；标题/色名支持 Enter 提交 |
| 豆距 | 预设或自定义有效数值 | 确认有效值后提交，可撤销 |
| 导出 PNG | 文档栏「导出 PNG」 | 导出完整已提交文档，选择位置；不进入历史 |

文档快捷键为 Ctrl+Z、Ctrl+Shift+Z / Ctrl+Y。文本字段中保留正常输入行为；模态定位图和预览隔离文档快捷键及浏览器撤销，防止背后的输入被修改。Escape 优先取消笔画/关闭模态图，再收起属性面板，最后交由应用退出全屏。预览和放大定位图提供焦点管理。

## 保存、导入与导出

`useBeadDocument` 对已提交文档进行 350ms 防抖保存，页面卸载刷新最新提交。临时笔画、候选预览不会保存。使用既有 `persistAppState`：先写本地镜像，再串行写桌面数据库。保存状态显示在文档名称旁。

`useImageImport` 独立管理图片解码、比例联动、转换和资源释放。每次请求有递增标识；取消/卸载终止 Worker 并使旧标识失效，迟到回调不更新文档。每张图最多 16MB、1600 万像素，解析结果每边 1–160 格。图片只在本机处理。失败和取消通过操作提示反馈。

PNG 与镜头缩放/平移无关，包含完整图纸、豆色编号、边缘辅助线、自适应坐标、数量与估算尺寸，不包含临时选色定位标记。桌面使用原生保存位置对话框；浏览器预览采用下载。取消导出不更改文档。物理尺寸是豆距估算，不代表屏幕/打印 1:1。

## 代码职责

| 模块 | 职责 |
| --- | --- |
| `BeadStudio.tsx` | 兼容原页面入口，转出工作台 |
| `BeadWorkbench.tsx` | 编排工具、面板、作业互斥、提示及快捷键 |
| `document.ts` / `useBeadDocument.ts` | 纯文档事务与历史 / 加载及自动保存 |
| `camera.ts` / `BeadCanvas.tsx` | 镜头计算 / 渲染和指针笔画会话 |
| `useImageImport.ts` / `ImportPanel.tsx` | 导入生命周期 / 参数界面 |
| `ColorPanel.tsx` / `ColorLocator.tsx` | 色卡管理 / 独立同色位置图 |
| `ShapePanel.tsx` / `DocumentPanel.tsx` | 填充加边 / 尺寸、新建及豆距 |
| `PreviewDialog.tsx` / `export.ts` | 统一前后预览 / 导出文件 |
| `model.ts` / `edit.ts` / `convert.ts` / `render.ts` | 沿用图纸模型、像素算法、转换、屏幕与导出绘制 |

后续新增编辑操作应复用文档事务；批量替换必须走预览。视图变化不得伪装为图纸修改，异步结果必须验证请求有效性后再提出候选文档。测试优先覆盖事务边界、算法性质和真实交互结果。
