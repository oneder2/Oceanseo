# 0.12.0 对话工作流验收报告

日期：2026-09-26。范围：将小汐助手与目标整理统一成一个以对话为中心的页面。没有修改生态 contracts、运行下游项目任务或同步用户项目资料。

## 交付内容

- 顶栏小汐、快捷键和「想法与目标」进入同一个页面。主区域是连续对话，支持补充、重试、停止等待、草稿恢复和中文输入法；阅读历史时不强制滚动。
- 理解图通过小图标弹出，以层级、文字和颜色区分已明确、待确认和尚缺信息。只读节点可引用回聊天，已保存行动也保留在关系中。
- 最终交付清单为右侧抽屉，显示具体新增/修改内容、依赖、执行入口及修改前参数。支持参数微调、逐条执行、全部可执行项、回执与最近一次安全撤销。
- 未明确分支单独等待；新补充、过期任务或目标状态阻止旧清单执行。后续对话携带最新微调、当前业务状态及回执，抑制重复新增。
- 已有事项允许更新标题、日期、周期和重要程度；原始记事本、创建信息及完成状态受到事务层保护。训练/旅行/食谱等具体内容仍进入相应业务页继续生成和保存。
- 沿用共用 AI 配置和旧版数据；新增对话、理解图、清单、回执纳入已提交数据备份。未发送文本仅作为本机草稿。数据发送边界见 [隐私说明](privacy-and-data.md)。

界面沿用 React/Tauri，采用海青与暖白纸面、简洁对话层级和按需打开的辅助面板；右侧抽屉提供执行控制，窄窗口维持可读性和键盘操作。没有引入外部组件模板。旧版整理台和侧栏源码保留用于追溯，但不再作为应用入口；旧版 UI 冒烟脚本仅对应历史版本。

主要文件：`src/goals/GoalConversation.tsx`、`UnderstandingMap.tsx`、`DeliveryDrawer.tsx`、`ConversationSettings.tsx`、`dialogue.ts`、`conversationData.ts`、`conversation.css`，以及 `src/App.tsx` 和 Rust 的 `goals.rs`、`planning.rs`、`tasks.rs`。

- Rust 45 项测试通过，覆盖结构化协议、本地 HTTP 模拟 AI、原子事务、版本检查、受保护任务字段、备份重启及参数修改撤销。

没有调用真实付费 AI、覆盖真实用户数据库或安装覆盖当前应用。模拟响应验证的是协议与业务交互，不证明实际模型理解质量。Mint/Ubuntu/Debian 多环境原生安装、第三方 Responses 兼容性和真实模型长对话仍需实机验收。
