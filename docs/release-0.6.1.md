# 潮汐计划 0.6.1：全屏模式

日期：2026-09-14。

窗口右上角新增全屏切换按钮，位于最小化和关闭之间；F11 切换全屏，Esc 退出。桌面端存在编辑弹窗时，Esc 优先交给弹窗。全屏时取消窗口外边距、圆角和阴影，保留导航和窗口按钮；禁止拖动全屏窗口。切换不卸载工作区，不改变图纸或表单内容。

桌面使用 Tauri 原生窗口全屏接口，补充查询与设置权限。按钮根据实际窗口状态更新，支持在窗口尺寸或焦点变化时同步；连续操作有互斥保护，操作失败会提示并恢复按钮。浏览器预览使用标准 Fullscreen API。

验证：

- TypeScript 检查和生产前端构建通过。
- Playwright 浏览器实测：按钮进入/退出、F11 双向切换、Esc 退出、全屏铺满视口、编辑中的图纸名称保留。
- Tauri IPC 模拟检查：原生查询/设置调用、Esc 优先关闭设置弹窗、外部状态变化后的同步、操作失败后的提示和按钮恢复。检查中发现并修复了同一次 Esc 同时关闭弹窗和退出全屏的问题。
- 浏览器控制台无错误或警告；截图：`output/playwright/fullscreen-0.6.1.png`。
- Tauri release 构建及 Debian 安装包打包通过。

原生窗口管理器下的实际进入/退出尚未自动化验证；本次没有覆盖安装用户正在使用的应用。

安装包：`src-tauri/target/release/bundle/deb/Tideplan_0.6.1_amd64.deb`。

安装后请退出托盘中的旧进程，再运行 `tideplan`；「偏好设置」应显示 0.6.1。
