# 1.0 发布准备计划

本轮交付 0.9.1 准备版。正式 1.0 以验收结果为准，不以功能数量或版本号为准。

执行记录见 [0.9.1 报告](release-0.9.1.md)。下列六项的本轮代码实现和本机自动化验证已完成；正式发布门槛中的真实桌面与服务验收仍待执行。

## 本轮实施顺序

1. 保存可靠性：持久化待写队列、启动重试、可见保存状态、导出前等待写入、恢复期间隔离写入。
2. 数据恢复：业务结构校验、覆盖前自动快照、失败不改写当前数据库。
3. 草稿保护：人物、训练、旅行未确认内容在页面切换和重启后可恢复；不自动进入正式计划。
4. 业务闭环：总览及每日提醒包含训练、旅行；休眠恢复时补发有限时间内的提醒并去重。
5. 配置可诊断：共用模型配置、AI 结构化输出连接测试、地图连接测试；不展示完整密钥。
6. 交付：自动化回归、隐私和安装升级说明、构建准备版安装包及验收记录。

## 正式发布门槛

- 自动化测试、类型检查、生产构建、Rust 测试和 lint 通过。
- 在干净配置中检查关键页面和失败恢复，不改写用户真实资料。
- Linux Mint / Ubuntu / Debian 实机：全新安装、覆盖升级、托盘、开机自启、通知权限、休眠唤醒、文件选择、窗口缩放。
- 使用发布支持的 AI 服务和地图账号验证权限、配额、超时、错误及真实路线。模拟返回不能替代此项。
- 从旧版本备份还原、从升级前真实资料副本升级；至少一次手工恢复演练。

实机和付费服务未验证项须在报告中列明，不能标记已完成。

## 后续独立迭代

训练按星期安排与单次调课、旅行导出、拼豆多文档、饮食复用人物画像暂不进入本轮可靠性修复。独立排期，避免变更历史记录语义。

范围仅 Oceanseo，不启动 GWorkspace 或 Ecosystem 下游任务，不修改生态契约。
