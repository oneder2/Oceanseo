# 账号、资料库隔离与设备会话

状态：2026-10-05 独立邀请制 `/v2` 已部署，生产 HTTPS、用户隔离、设备撤销、重启与备份恢复验证通过。客户端体验调整及 Linux/Pixel 联合验收通过，公开安装包尚未更新。见 [当前交付报告](account-center-deployment-2026-10-05.md)。原公开 0.18.0 仍使用 `/v1/vault` 个人令牌和手动确认同步。

## 内测边界

新增独立 `/v2/*` 邀请制服务，不改原私人数据库、令牌或 `/v1/vault`。使用用户名和密码登录；一个一次性邀请码只能创建一个用户，默认 72 小时有效。没有公开注册、邮箱找回、第三方登录或官方 AI 额度。用户忘记密码由维护者在服务器本机交互重置，不在命令行中传密码。登录后的账号设置提供受当前密码和 `DELETE` 确认词保护的云端账号删除；删除会原子移除云端资料库、会话和已消费邀请码，本机资料保留为离线副本，便于用户先导出后自行清理。

每个用户拥有自己的云端资料库；服务端只从设备会话推导用户，不接受客户端指定资料所有者。每次登录创建独立设备会话，有效期 30 天，最多同时 10 台设备。设备列表可查看名称、平台、创建时间、最后访问及到期时间；支持撤销单台或其他所有设备。修改或管理员重置密码会撤销全部设备，必须重新登录。

会话和邀请码只在服务端保存 SHA-256 摘要；密码使用随机盐和 scrypt，不保存明文密码。认证有持久限流，请求不记录正文或 Authorization。服务只监听回环地址，公网必须使用 HTTPS 代理。当前采用全局与用户名限流，不冒称具备完整 WAF 或抗分布式攻击能力。

## 本机所有权

原有离线资料库保持在原目录，不自动导入账号。账号目录以「规范化服务器地址 + 用户 UUID」的 SHA-256 区分，用户名重名或不同服务器不会误用同一资料库。每个账号分别保存：

- 任务、全部业务 app_state、目标与同步共同基线。
- 浏览器草稿、保存队列、目标操作重试、恢复提示和同步回执。
- AI 配置、地图凭据、主机采集凭据、桌面工作视察数据库与导出目录。
- 同步前安全副本和迁移备份。

Android 会话用现有 Keystore 加密，Linux 会话文件权限 600，账号目录 700。密码只存在登录/修改请求中，不存入本机配置，也不传回界面。凭据不进入业务备份。

一个原生进程固定绑定一个账号。选择另一份本机资料库只更新下次启动的选择，不热替换数据库；旧进程中的延迟请求仍写入旧资料库。界面必须先保存、冻结业务写入并完成原生切换流程，不能只刷新网页而宣称切换成功。启动时先取得原生绑定的账号，再初始化存储命名空间，最后加载业务组件。

退出、过期或撤销会话不删除本机资料，仍可在该资料库离线记录，但不能继续云端同步。损坏/缺失的已选账号配置会阻止启动，不静默回退到其他人的资料库。重新登录必须返回原用户和原云端资料库；资料库更换会被拒绝，需维护者处理。

本机目录隔离防止应用串数据，并非操作系统用户之间的加密沙箱。服务器仍可读取云端业务资料，没有端到端加密。

## 服务部署准备

以下独立部署步骤已在生产完成；不得指向现有 v1 数据库。首次安装脚本拒绝覆盖已有部署，后续更新应遵守 [运维说明](accounts-operations.md)。

1. 建立无登录权限专用用户 `oceanseo-accounts`，私人目录 `/var/lib/oceanseo-accounts`（700）。代码根目录 `/opt/oceanseo-accounts` 下应包含 `services/accounts/` 和共享校验模块 `services/sync/server.py`，保留 Python 模块目录结构。
2. 使用 `accounts.env.example` 配置仓库外 `/etc/oceanseo-accounts.env`，root 所有、600；安装 `oceanseo-accounts.service`，监听 `127.0.0.1:4791`。scrypt 最多同时两次计算，服务最多 16 个请求线程；1 GiB 内存上限仍须实际负载验收。
3. Caddy 仅将 `/v2/*` 代理到 4791，保留原 `/v1/vault`、采集器和下载页；修改前备份、验证配置、完成隔离测试。不要直接开放 4791。
4. 使用专用服务账号在代码根目录运行 `python3 -m services.accounts.admin --database /var/lib/oceanseo-accounts/accounts.sqlite3 invite --hours 72`。邀请码只输出一次，通过私人渠道交给测试者，不放到下载页或 Git。
5. 密码重置：同一管理员命令的 `reset-password 用户名` 子命令会使用隐藏输入并撤销全部会话。
6. 采用 `services/sync/backup.py` 在线备份整个账号 SQLite，备份包含账号、密码哈希、会话摘要、邀请码状态和资料库，必须私人保管并配置异地存储。恢复较旧备份会使旧会话/邀请码状态回退，恢复前应停服并制定全会话撤销与重新邀请流程；客户端资料 revision 回退仍会停止同步。

账号数据库使用 `PRAGMA user_version=1`。识别到未来版本或其他服务的数据表时拒绝修改，不允许直接降级或复用 v1 数据库。

## 当前实现与剩余门槛
