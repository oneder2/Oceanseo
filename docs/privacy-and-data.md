# 数据与服务说明

应用公开名称为「Oceanseo」，早期名称为「潮汐计划」。Linux 可执行文件和软件包名 tideplan，桌面标识为 com.tideplan.desktop。公开 0.18.0 与邀请账号开发版的同步行为不同，以下明确区分。

## 本机数据

任务与已提交生活数据保存在 SQLite。生活数据的待写内容另存本机 WebKit 存储，数据库写入失败后可重试，重启会优先恢复待写内容。目标关系与整批行动使用独立事务和待写请求；重启发现未取得回执的请求时会提示重试，不盲目覆盖新数据。人物、训练、旅行编辑草稿也暂存本机，不会自动变成正式日历安排。顶栏显示生活数据及目标操作的保存状态；单项任务保存以操作完成提示为准。存储空间耗尽时请保持应用打开并重试，不要清理缓存。

「偏好设置 → 数据备份与恢复」导出已提交的任务、生活数据、提醒配置和助手记录。导出会先等待数据库写入完成；**任务、人物、训练和旅行的编辑草稿、工作观察数据库和服务密钥不在此 JSON 备份范围内**。新对话页面的未发送输入仅暂存本机，不纳入 JSON 备份；旧版助手记录中的草稿仍随历史记录保留。备份包含姓名、生日、偏好和备注，应作为私人文件保管。

恢复会先校验所有业务文档，然后在应用数据目录的 `migration-backups/before-restore-*.json` 创建当前数据副本，再原子覆盖数据库。副本创建失败则不覆盖。恢复成功后清除编辑草稿，重载页面；设置中显示本次副本路径。副本不自动清理，避免误删最后可恢复的数据；确认新数据无误后可自行整理这些文件。

Linux 默认应用数据目录为 `$XDG_DATA_HOME/com.tideplan.desktop`，通常在 `~/.local/share/com.tideplan.desktop`。WebKit 草稿和缓存位于系统为该应用分配的数据/缓存位置。卸载软件包不等于删除这些用户数据。需要迁移完整运行环境时，退出托盘进程后备份应用数据目录，并单独保存服务配置；不要把带密钥的目录上传到公共仓库。

人物的「归档」保留历史关联，**不等于删除个人资料**。档案底部的「清除个人信息」经再次确认后清空姓名、生日、偏好和所有档案备注，并以匿名档案保留训练/旅行关联；同时移除该人物的编辑草稿。既有计划/AI 结果中的文本、第三方记录、导出文件及恢复前副本不会自动清理，需单独检查。彻底清理应用资料需退出应用后检查并移走该应用专用目录及 WebKit 存储，建议先保留加密备份。

任务编辑器和事项记事本也会暂存修改，重新打开对应事项可继续；新事项草稿从「添加计划」继续。保存成功后清除对应草稿，或使用「放弃草稿」恢复正式内容。暂存不代表该事项已保存进数据库或纳入备份。

## 发送给第三方的数据

- 主机与服务：档案、费用、期限、维护日志、监测样本与保存的摘要进入本机 SQLite 和完整备份，不参与当前核心同步。采集令牌单独保存，Android Keystore 加密、桌面权限 600，不进入业务备份或 AI。HTTP 服务检查访问用户指定的端点，资源采集向绑定地址发送独立令牌，不跟随重定向。检查仅在应用运行且可见时按设置执行；原始响应正文和服务器私密日志不采集。
- 主机 AI：用户确认后发送预览中的运行摘要，剔除地址、路径、订单号、维护日志和凭据引用；名称、项目及用途仍属用户内容。订单识别发送用户选定的文本/图片，需先遮盖个人与支付信息；图片只用于本次识别，不保存在档案。AI 结果需人工核实，不执行远程操作。既有助手的主机摘要范围默认关闭。详情见 [主机与服务](infrastructure.md)。

- 公开 0.18.0 的个人同步默认不连接服务。用户配置自己的同步地址与独立访问令牌后，“检查更改”下载服务端资料；“确认同步”才上传。一个个人令牌只用于同一人的设备，不作为多个内测用户的共用账号。
- 邀请账号开发版：登录并确认打开账号后，该账号默认前台自动同步，无冲突首次连接也会自动上传/下载已保存资料，不再逐次确认。原本机资料不自动导入账号，明确关闭的设置保持关闭。同步范围为任务（包括笔记、日期、完成状态）、目标与已保存对话、理解图、交付清单和执行回执。不上传 AI／地图／同步密钥、通知时间或未提交草稿，生活模块暂不参与。不可可靠合并的同一内容会暂停并询问保留哪份，保留两份安全副本。
- 邀请制 `/v2` 已部署，使用独立用户、资料库与设备会话，不复用私人 `/v1` 令牌或资料。账号密码保存为加盐 scrypt 哈希；邀请码及设备 token 保存摘要。云端业务数据通过 HTTPS 传输但不是端到端加密，服务器维护者及 TLS 代理提供方有访问内容的技术能力。账号资料库使用私有权限而不是磁盘加密。
- 每次同步提交前本机保存两端版本和完整本机备份，设置可导出最近成功同步前的副本；副本包含私人资料，不自动清理。断开连接仅清除本机服务配置，不删除任一端的资料。删除任务会在下次确认同步后传播；墓碑保留以防旧设备复活记录。服务端彻底删除或停止使用需要维护者删除对应独立资料库及其备份，并协调客户端，不能只删掉云端文件再让旧设备自动重传。详情见 [同步说明](cross-device-sync.md)。
- 2026-10-04 部署的个人域名 `oceanseo.gellaronline.cc` 经过 Cloudflare 代理，HTTPS 在代理层终止后再连接源站；没有端到端加密，代理提供方有处理解密请求内容的技术能力。服务器 SQLite 与本次取回的连接参数/备份也不是磁盘加密文件，仅使用私有权限。每日自动备份目前在服务器本地，并非持续异地备份。首次部署未自动连接电脑/手机或上传个人记录，详情见 [部署报告](server-deployment-2026-10-04.md)。

- 小汐对话与目标推进：统一页面发送最近 40 条对话、当前理解图、待执行清单、最近至多 100 条回执、想法原文、目标/任务摘要、业务对象名称、本机清点摘要以及精灵设置和偏好。日历、饮食采购、项目统计可选择分享；任务记事本仅在主动勾选后发送。发送前可在对话设置中预览上下文。人物档案、项目源码及路径不作为规划上下文发送；聊天中主动填写的信息仍会发送。详见 [对话工作流说明](conversation-workflow.md)。

- 最近 160 条对话、理解图、清单、执行回执及已保存复盘纳入本机数据库和 JSON 备份，原始想法另有记录；未发送输入仅暂存本机。晨晚及每周自动清点使用本机记录，不后台调用 AI。删除或恢复本机记录不会清理既有备份或服务商日志。

- AI：食谱条件、周报所需项目摘要、选中人物的规划字段、训练/旅行条件会发送给设置的 BASE_URL。人物原始生日及私人备注不会进入人物画像上下文。不要在其他会发送的字段中放入不希望分享的内容。
- 拼豆 AI 图像提炼：主动点击识别或生成后，发送当前选中图片（最长边 1024 px、重新编码 PNG）及设计说明，不附带其他业务数据或原文件路径。原图和生成插画暂存当前页面内存，可另存 PNG；仅已应用的拼豆图纸纳入备份。本机转图不联网，服务需要额外支持 Responses 图片生成工具。详见 [照片提炼与交界净化](bead-ai-and-cleanup.md)。
- 共用 API_KEY、BASE_URL 和模型名称。服务必须支持 Responses API 的 JSON Schema 结构化输出；新版对话工作流不需要 function calling。调用使用 `store: false`；服务商日志与数据留存仍取决于服务商政策。
- AI 连接测试只发送固定短文本，不含个人资料，可能收费。测试成功代表本次结构化请求通过，不代表所有模型、权限、额度或复杂计划都会成功。
- 高德：地点查询和路线坐标发送至高德 Web 服务。OpenStreetMap 底图请求包含网络地址和查看区域。地图 Key 不发送给 AI，不放入 JSON 备份。
- 工作观察：只在人工确认同步后写入 GWorkspace；本轮没有运行下游项目任务或同步用户项目资料。

Linux 密钥保存于本机权限为 0600 的配置文件，不代表磁盘加密。Android 0.14.0 起使用设备 Android Keystore 的不可导出 AES-GCM 密钥加密 AI / 地图配置，再写入应用私有目录；这不是整个任务数据库的加密。设置只返回密钥是否存在及末尾提示，不返回完整密钥。可在设置中清除 AI / 地图密钥。

公开 Android 内测包为 `com.tideplan.mobile.debug`，新账号界面验收包为 `com.tideplan.mobile.uiuxqa`，与正式预留包 `com.tideplan.mobile` 分别保存数据。新账号开发版有独立资料库及前台自动同步，但旧公开包没有该账号入口，Android 挂起后不承诺持续同步。Android 系统云备份与设备转移已关闭，迁移需使用应用内 JSON 备份（不包含服务密钥）。卸载／清除应用数据会删除本机资料和设备密钥，操作前应导出备份。

退出账号停止同步但不删除本机或云端数据；当前没有用户自助账号注销接口，内测者需要通过邀请渠道联系维护者，协调设备、云端资料及备份清理。正式开放内测前应明确支持联系方式、删除流程与备份保留期限。运维见 [账号服务说明](accounts-operations.md)。

Android 每日提醒交给系统 AlarmManager；提醒正文不显示姓名、任务详情或训练数据，点击后进入应用查看。未申请精确闹钟特殊权限，系统省电可能延迟提醒。重启、时区／时间变更和应用升级时重新安排；强行停止应用后需手动打开恢复。通知权限只在用户点击授权测试时请求。

## 提醒边界

Android 采购清单可通过系统分享面板发送 CSV / Markdown 文件。文件仅包含当前来源筛选下的物品、数量、分类、采购状态和食谱来源；不附带 API 密钥或其他业务数据库。点击分享会在应用专用缓存中生成独立快照，由用户选择接收应用，授予该文件的临时读取权限；关闭面板不代表已经发送。最近的分享快照保留供接收应用读取，再次分享时清理超过 24 小时的旧快照，系统也可回收缓存；已发送到其他应用的副本需在那里管理。

「手机提醒检查」在设备本机读取应用通知、每日提醒频道、电池优化、省电模式、系统时区和已安排的时间。系统设置入口只打开对应设置页，不自动更改权限或取消电池优化。显示的时间是调度目标，不是已送达回执。

桌面端每日提醒包含待办、关键日期、当天未完成训练和旅行。应用启动/恢复焦点及运行中每 30 秒检查一次；两小时内的错过时段合并补发一次，按本地日期和时间去重，较早的提醒不追发。需要允许系统通知并保持应用或托盘进程运行。退出进程、系统关机或通知被系统拦截时不能保证送达。Android 的调度与正文范围见上文。
