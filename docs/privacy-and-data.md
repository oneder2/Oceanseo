# 数据与服务说明

应用公开名称为「潮汐计划」，源码仓库名 Oceanseo，Linux 可执行文件和软件包名 tideplan，桌面标识为 com.tideplan.desktop。

## 本机数据

任务与已提交生活数据保存在 SQLite。待写内容另存本机 WebKit 存储，数据库写入失败后可重试，重启会优先恢复待写内容。人物、训练、旅行编辑草稿也暂存本机，不会自动变成正式日历安排。顶栏显示生活数据写入状态；任务保存以操作完成提示为准。存储空间耗尽时请保持应用打开并重试，不要清理缓存。

「偏好设置 → 数据备份与恢复」导出已提交的任务、生活数据及提醒配置。导出会先等待数据库写入完成；**编辑草稿、工作观察数据库和服务密钥不在此 JSON 备份范围内**。备份包含姓名、生日、偏好和备注，应作为私人文件保管。

恢复会先校验所有业务文档，然后在应用数据目录的 `migration-backups/before-restore-*.json` 创建当前数据副本，再原子覆盖数据库。副本创建失败则不覆盖。恢复成功后清除编辑草稿，重载页面；设置中显示本次副本路径。副本不自动清理，避免误删最后可恢复的数据；确认新数据无误后可自行整理这些文件。

Linux 默认应用数据目录为 `$XDG_DATA_HOME/com.tideplan.desktop`，通常在 `~/.local/share/com.tideplan.desktop`。WebKit 草稿和缓存位于系统为该应用分配的数据/缓存位置。卸载软件包不等于删除这些用户数据。需要迁移完整运行环境时，退出托盘进程后备份应用数据目录，并单独保存服务配置；不要把带密钥的目录上传到公共仓库。

人物的「归档」保留历史关联，**不等于删除个人资料**。档案底部的「清除个人信息」经再次确认后清空姓名、生日、偏好和所有档案备注，并以匿名档案保留训练/旅行关联；同时移除该人物的编辑草稿。既有计划/AI 结果中的文本、第三方记录、导出文件及恢复前副本不会自动清理，需单独检查。彻底清理应用资料需退出应用后检查并移走该应用专用目录及 WebKit 存储，建议先保留加密备份。

任务编辑器和事项记事本也会暂存修改，重新打开对应事项可继续；新事项草稿从「添加计划」继续。保存成功后清除对应草稿，或使用「放弃草稿」恢复正式内容。暂存不代表该事项已保存进数据库或纳入备份。

## 发送给第三方的数据

- AI：食谱条件、周报所需项目摘要、选中人物的规划字段、训练/旅行条件会发送给设置的 BASE_URL。人物原始生日及私人备注不会进入人物画像上下文。不要在其他会发送的字段中放入不希望分享的内容。
- 共用 API_KEY、BASE_URL 和模型名称。服务必须支持 Responses API 的 JSON Schema 结构化输出。调用使用 `store: false`；服务商日志与数据留存仍取决于服务商政策。
- AI 连接测试只发送固定短文本，不含个人资料，可能收费。测试成功代表本次结构化请求通过，不代表所有模型、权限、额度或复杂计划都会成功。
- 高德：地点查询和路线坐标发送至高德 Web 服务。OpenStreetMap 底图请求包含网络地址和查看区域。地图 Key 不发送给 AI，不放入 JSON 备份。
- 工作观察：只在人工确认同步后写入 GWorkspace；本轮没有运行下游项目任务或同步用户项目资料。

密钥保存于本机权限为 0600 的配置文件，不代表磁盘加密。设置只返回密钥是否存在及末尾提示，不返回完整密钥。可在设置中清除 AI / 地图密钥。

## 提醒边界

每日提醒包含待办、关键日期、当天未完成训练和旅行。应用启动/恢复焦点及运行中每 30 秒检查一次；两小时内的错过时段合并补发一次，按本地日期和时间去重，较早的提醒不追发。需要允许系统通知并保持应用或托盘进程运行。退出进程、系统关机或通知被系统拦截时不能保证送达。
