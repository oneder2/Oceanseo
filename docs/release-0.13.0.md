# 0.13.0 拼豆照片流程与交界净化验收

日期：2026-09-27。范围：修复导入图案交界混色，并增加 AI 照片主体提炼、插画生成与拼豆转换。此前 0.12.0 对话工作流改动保留；没有修改生态 contracts、执行下游项目或覆盖用户数据库。

## 交付

本机转换增加平涂源判别与有空间支持的边缘采样，并在最终厂家豆色分配后执行连通区域净化。处理长混色线、三色交点与小簇偏色，保留透明区域、稳定色块与明显亮暗细节；整块判断和相邻色块约束避免制造新的孤立碎片。默认照片导入为较强去杂色并启用交界净化，可关闭作对照。原始像素模式和既有图纸不自动改色。

导入面板增加「AI 提炼主体」：识别照片 → 修改主体/特征 → 选择风格和背景 → 生成插画 → 原图对比 → 本机拼豆预览 → 应用或取消。共用现有 AI 凭据，图片模型可配置并暂存本机；支持导出插画 PNG、自选位置、取消等待、失败保留上次结果及应用后的撤销。

设计沿用 React/Tauri 与既有海青色工坊，将步骤集中在可收起的侧面板；大图对比按需打开，画布继续占据主要区域。没有使用外部组件模板。修复了原图对比弹窗按 Esc 时连带收起导入面板的问题。

代码集中在 `src/beads/boundaryCleanup.ts`、`resample.ts`、`convert.ts`、`useBeadImageAi.ts`、`useImageImport.ts`、`AiImagePanel.tsx`、`ImportPanel.tsx`、`export.ts` 与 `src-tauri/src/bead_ai.rs`。使用步骤、算法取舍与服务要求见 [说明](bead-ai-and-cleanup.md)。

## 视觉对照

同一输入、较强去杂色、MARD 色卡，比较关闭/启用本次新处理。合成图使用 64×64 / 最多 24 色；人像 64×64 / 最多 16 色；室外照片 96×64 / 最多 16 色。原图与前后结果见 `output/playwright/bead-boundary-comparison.png`。

| 样例 | 孤立单豆（前 → 后） | 1–4 格小色块（前 → 后） | 结论 |
| --- | --- | --- | --- |
| 两/三色交点与混色长线 | 2 → 1 | 2 → 1 | 已知混色残留 0；保留一颗白色高光及黑色细线 |
| 四色斜线交界 | 64 → 0 | 64 → 0 | 消除缩图引入的额外颜色，最终保持 4 色 |
| NASA 人像 | 126 → 35 | 187 → 77 | 碎片明显减少，保留大轮廓 |
| SpaceX 室外发射场 | 17 → 12 | 35 → 23 | 保持连续色调采样，小色块减少 |

孤立点数不是正确性分数，其中可能包含星光、眼睛或装饰。合成图的已知错误可以要求零残留；不能据此承诺任意真实照片都零误判。复杂人像建议通过新增 AI 流程先得到适合低分辨率的插画再转换。样例来源与复现脚本见 [说明](bead-ai-and-cleanup.md)。
