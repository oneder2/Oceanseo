## 定位与设计方向

Oceanseo 是用户的个人生活中枢，而非服务器控制台或又一个待办列表。用户决定方向，小汐帮助澄清，应用把可确认的结果接入真实工作流。

- 下载页任务：先辨认产品和 Android 内测版本，再决定下载；桌面访客可扫码到手机，并取得 Linux 包。无需注册，不展示或发放私人同步令牌。
- 色彩：深海墨 `#153d3a`、海玻璃 `#397c70`、雾白 `#f1f7f5`、纯白 `#ffffff`、珊瑚 `#cf7058`、细线 `#d7e5df`。白/墨构成阅读骨架，海绿承担状态与操作，珊瑚只用于小面积重点；不使用整屏渐变或发光光球。
- 字体：Oceanseo 与英文展示文字采用自托管 Outfit；中文正文用系统中文无衬线；版本、散列值使用等宽字体。字号按断点固定，不按视口连续缩放，字距保持 0。
- 布局：全幅产品背景的居中首屏、连续无框内容带、一个交互预览、真实内测截图、下载与边界说明。首屏保留下一节线索，手机下载按钮可持续找到，不采用层层套卡片的结构。
- 动效：GSAP 负责短入场及单次滚动显现；桌面可使用 Lenis，手机保持原生滚动。减少动态效果、后台页面、键盘焦点和弹窗都优先于动画。
- 标志性体验：一个示例想法贯穿“说出想法 → 理清目标 → 确认行动”，展示未来应用内的紧凑信息层级；旁边展示现有版本真实截图，区分交互方向与实际已发布界面。

## 参考库调研

本轮查阅官方仓库/文档、许可证与 npm 元数据。用户所写 GASP 按 GSAP 理解。检索快照版本：Lenis 1.3.26、GSAP 3.15.0、Vanta 0.5.24；版本号不是持续更新保证。

| 库 | 候选与适用场景 | 采用决定 | 风险与边界 |
| --- | --- | --- | --- |
| Lenis | 官网长页面桌面滚动，与 GSAP ScrollTrigger 共用 ticker | 下载页仅细指针/可悬停设备启用；Android 和减少动态效果保持原生 | 不接管聊天、任务列表、弹窗滚动、日期选择器、地图或拼豆画布；单一 RAF，离开页面清理 |
| GSAP | timeline、ScrollTrigger、matchMedia、context；预览步骤切换、抽屉/内容短过渡 | 本轮选择 core + ScrollTrigger，依赖精确锁定 | JSX 生命周期和 reduced-motion 必须处理；不是纯 MIT，采用其 Standard no-charge license；无需装全部插件 |
| Vanta | WAVES 可以呼应海洋品牌；NET/FOG 是背景演出而非业务组件 | 不进入默认下载页或应用工作区 | Three.js/p5/WebGL 的持续渲染、触控与电池代价，无助于读任务；若未来做独立桌面品牌场景再单独压测，不使用旧示例 CDN 链接作为版本维护策略 |
| React Bits | AnimatedContent/FadeContent 的一次性显现；Stepper 的长表单进度；Dock 的导航组织参考 | 参考交互模式，本轮不复制组件源码或安装整套 | 实际 LICENSE.md 为 MIT + Commons Clause，允许产品集成但限制独立组件售卖/分发；AnimatedContent 默认隐藏元素需解决无 JS/失败时内容不可见问题 |

不采用磁吸下载按钮、正文模糊/逐字动画、自动轮播、闪烁数字、装饰粒子。它们会增加点击不确定性、阅读负担或触控冲突。React Bits 的 Stepper 只适合旅行/训练等长表单，不把用户已明确要求的单界面对话改回多步向导。

## 应用端具体落点

- 阅读基础：中文正文桌面至少 14 px、手机输入及主要正文 16 px；不对正文应用模糊/透明度入场。日期、计数及预算用稳定布局，长数字允许换行，不以省略号隐藏关键数据。
- 导航：手机维持“今天 / 助手 / 工具”，桌面维持工作区分类；泛用日历、人物和设置保留全局入口，专业工具不挤进核心对话。移动工具选择缩短到一次可扫描的分组列表。
- 核心对话：对话占主区域；理解图为只读弹层，最终交付清单桌面右抽屉、手机全屏侧层。参数微调、逐条/批量确认、等待依赖与执行回执始终明确，沿用现有事务和防重复机制，不用 Stepper 替代对话。
- 桌面透明感：半透明只用于窗口边缘与导航背景，正文、表单、食谱和清单保留足够不透明底色；不同桌面壁纸下验收对比度，而不是简单降低整个窗口透明度。
- 动效组件：共用抽屉/弹层采用 160–220 ms 的短位移，成功反馈不闪烁、不改变布局；简单状态优先 CSS。GSAP 只用于确实需要组织时序的部分，不把下载页的 Lenis 带进业务页面。
- 长表单：训练与旅行按“对象与目标 / 时间与预算 / 细节与确认”组织，允许返回而不丢草稿。React Bits Stepper 只作为模式参考；继续使用仓库现有表单、日期选择器与校验逻辑。
- 专业工具：拼豆保持大画布和上下文工具栏，地图维持独立触控手势；主机列表首先呈现异常、到期、费用与最后采样时间。不引入 Vanta 持续背景。
- 验收目标：先做核心动作及无障碍回归，再补动效；手机 44 px 以上触控目标，弹层焦点不逃逸，Escape/返回关闭后恢复焦点。目标性能指标需在真机实测，不用桌面浏览器模拟代替 Android 原生验收。
