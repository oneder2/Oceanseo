# 0.9.2 拼豆色卡与图像转换

## 色号的含义与来源

拼豆没有跨品牌统一的色号标准。0.9.1 的 B01、B02 是图纸内部索引，并非厂家色号。0.9.2 导入默认选择 MARD，也可选 COCO、漫漫、盼盼、咪小窝或自定义原色。画布、定位图、工具栏、用色清单和 PNG 均读取保存的色号。

数据来自 [Zippland/perler-beads 的历史版本 2519daf1628534e414bc7a10f0472dc32000bde4](https://github.com/Zippland/perler-beads/blob/2519daf1628534e414bc7a10f0472dc32000bde4/src/app/colorSystemMapping.json)，该版本以 Apache 2.0 发布。当前上游许可已变化，本项目仅使用上述历史版本的数据，未采用后续版本代码或数据。原始 291 条映射完整保存在 `src/beads/palettes/catalog.json`，仅调整 JSON 排版；运行时使用 MARD A–H、M 系列对应的 221 个普通色，并保留另外四品牌的原始对应编号。没有自行生成厂家色号或 RGB。

这是**社区整理的品牌色号及屏幕近似色对照表**，不是厂家授权、官方测色数据，也不能证明不同品牌同一行的实体颜色完全一致。尚未逐项用实体色卡测量。购买时应核对品牌、系列、规格、批次及实物颜色。透明、珠光、荧光等特殊系列不参与自动匹配；本版不是各品牌全部在售产品目录。许可全文与署名随应用打包，位于 `public/licenses/`，豆色面板提供来源和许可入口。

## 使用方式与兼容

- 导入 → 拼豆品牌：选择目标品牌后生成预览。像素模式保留格点结构；选品牌会改变颜色，选“自定义原色”才逐像素保留 RGB。
- 豆色 → 品牌色卡与配色转换：已有图纸可预览转换整个配色，应用后可撤销；也能按厂家色号添加绘画颜色。
- 旧图纸仍以自定义配色打开，不自动改色。纯自定义图纸保留 B 编号；混合图纸的自定义色使用 U 编号，以免与 MARD 的 B 系列混淆。混合多个品牌时加品牌前缀。
- 改名称保留厂家身份；改变 RGB 会取消厂家身份并成为自定义色。备份还原校验品牌、色号、色值与色表版本的一致性。文档比较与撤销包含这些元数据。

## 修正的原因和算法

旧算法只在八邻域多数颜色一致且色差较小时替换单个像素。与周围差异很大的彩色杂点会被误当成细节，小簇噪点和相近颜色交错也难以处理。缩图依赖浏览器滤镜，复杂细纹的采样结果不够可控。

新版照片转换依次执行：

1. 在 Worker 中按覆盖面积加权缩图，使用预乘 alpha，避免透明区域隐藏 RGB 污染边缘。保持比例，空余部分透明留白。像素模式单独使用最近邻，不降噪。
2. Lab 邻域支持分析，识别缺少同色邻居、周围颜色一致且亮度接近的孤立偏色。温和半径 1，较强半径 2；较强模式可处理部分成对/小簇杂色。使用真实邻居作为代表，避免独立通道中值凭空组合新色。
3. 保边双边平滑；五位 RGB 直方图、加权 Lab 聚类，最多十轮。聚类代表色只从本簇样本选取，避免借用其他簇中的罕见颜色。
4. 选品牌时使用 CIEDE2000 匹配厂家色表，并用同样的色差计算分配最终豆色。比普通 Lab 欧氏距离更好地区分部分深色、低饱和度色调。公式验证使用 [Sharma 等公开补充测试数据](https://hajim.rochester.edu/ece/sites/gsharma/ciede2000/)。
5. 在最终配色上进行保边邻域约束：源图差异大的边缘降低邻域投票权重，限制改色增加的误差，交替方向迭代且只接受能量下降。最后合并重复色、删除未用颜色、重新映射格点。

不使用抖动。用户仍可选择关闭、温和、较强；色数上限 2–48。较强模式会简化部分真实细纹，算法没有语义理解，无法保证每颗孤立豆都是噪声。亮度接近的孤立有色装饰也可能被简化，应检查预览；需要原样保留时使用像素原稿与自定义原色。

输入限制仍为 16 MB / 1600 万像素，图纸最大 160×160。主线程解码和读取原尺寸像素，传输缓冲区到 Worker 后执行采样与转换；可取消 Worker。相比旧版多保留一份原尺寸 RGBA，最大约 64 MB，加上解码与 Canvas 内存，极大图片仍建议先缩小。

## 验证边界

回归覆盖单点和成对偏色、细黑线和白色高光、确定性、透明边缘、隐藏 RGB、棋盘纹面积平均、颜色上限、色表唯一性、品牌匹配、色号编辑与撤销、旧文档、备份验证。CIEDE2000 用公开标准输入/输出校验。

另使用 NASA Eileen Collins 公共领域人像，通过 [scikit-image v0.24.0](https://github.com/scikit-image/scikit-image/blob/v0.24.0/skimage/data/astronaut.png) 获取，做 64×64、16 色、较强去杂色的旧版/新版/品牌匹配视觉对照。本地结果在 `output/playwright/bead-quality-comparison.png`。孤立点数仅反映拼放碎片程度，包含真实细节，不能单独当作质量分数。该样本与合成测试不代表所有人像、动漫、宠物和风景；还需使用用户实际原图继续评估。
