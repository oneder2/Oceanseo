# 账号体验调整与独立服务上线

本地日期 2026-10-05；服务器部署时间 2026-10-06 00:18 UTC。本报告描述本次真实交付，不代表整个 Android 内测或 1.0 发布完成。

## 用户体验

- 顶栏和桌面侧栏提供独立「我的账号」，负责登录、邀请码注册、设备、密码及同步状态。账号不再混在偏好设置里。
- 偏好设置保留提醒、开机启动、备份等日常选项。AI、地图及手动同步/服务诊断收进默认关闭的「高级与开发者设置」。账号服务地址和设备名称另置于收起的高级连接选项。
- 新账号默认连接正式域名，默认前台自动同步，包括无冲突的首次连接；已明确关闭的设置不被重置。不自动搬运原本机资料。
- 可合并字段自动处理，离线保留并重试；只有真正无法确定的内容才询问「这台设备 / 另一台设备」保留哪份，仍留安全副本，不显示协议、revision 或令牌。
- 已保存导入后保留全局载入锁；刷新失败可重试，不让旧界面回写新数据。会话失效只需重新登录，成功后恢复，完整性异常不会被重新登录掩盖。

保持现有 React/Vite 海玻璃风格，阅读区域不透明，状态克制，移动控件至少 44px；没有引入新的组件框架。设计技能用于账号/设置分层、渐进展示和移动布局，Playwright 用于浏览器交互与截图检查。

- 生产 HTTPS 验证通过：无邀请注册拒绝、邀请码单次消费、两个用户独立资料库、同账号设备读取、外来写入拒绝、过期 revision 拒绝、设备撤销。
- 仅重启 v2 后验证资料、用户隔离与撤销状态保持；在线备份恢复到独立目录检查通过。精确生成的两个合成用户已停用，会话已撤销；没有创建或分发真实测试者邀请。
