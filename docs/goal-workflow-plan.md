# 目标推进工作流实施与验收

范围：Oceanseo 内从原始想法到目标、子目标、行动、业务入口和复盘的完整流程。保留现有任务契约；关系作为本地关联数据保存，不修改 contracts，不启动下游任务。

界面方向：服务于事务混乱时的个人用户；安静、清晰、可回退。整理台采用左侧原始想法、右侧方案的纸面布局；首页突出单张“现在先做”卡。沿用现有中文字体和衬线标题、海青与暖白表面。只为状态反馈使用轻动效，并支持减少动画。标志性元素是从目标沿细线展开到下一步行动的路径。React/Vite/Tauri 保持不变，不需要外部组件参考。

## 交付清单

- 独立想法收集箱，原文、补充、暂缓及整理结果持久化。
- 目标/子目标/行动关联，完成标准、依赖、预计耗时、阻碍、暂停与复查日期。
- AI 对照已有任务/目标，输出可编辑方案、少量澄清问题及暂缓建议；保留方案和来源。
- 一次采用，任务与关联数据在本地原子保存；版本冲突检测、重复提交幂等、真实回执、可安全撤销。
- 首页依据日期、依赖、暂停、时间和精力推荐行动；进入具体业务对象或携带条件的新建流程。
- 任务/训练等真实记录驱动进展；晨间安排、晚间清点、周期复盘与下次检查；自动化范围可配置。
- 备份恢复、旧数据兼容、重启恢复、失败与取消处理。
- 回归测试、浏览器关键流程验收、生产构建、安装包及报告。

## 验收重点

混乱输入形成少量可检查目标；复用已有任务；采用/重试不重复创建；错误不留下半套计划；前置任务完成后后续行动进入候选；暂停和容量限制生效；业务入口定位到对象；复盘不虚构成果；重启/备份恢复保留关系。真实 AI 服务和多系统原生安装未执行时明确标注。

## 完成审计（2026-09-20）

| 要求 | 实现与验证 |
| --- | --- |
| 收集混乱想法并保留上下文 | 独立收集箱、输入暂存、聊天交接；隐私与原文保存测试、浏览器重载通过 |
| 目标、子目标与可执行行动 | 可编辑方案、完成标准、依赖、阻碍及暂缓；结构和循环依赖测试通过 |
| 一次纳入现有操作流程 | SQLite 原子采用、旧任务复用、幂等回执、安全撤销；事务/冲突/重启测试通过 |
| 明确现在做什么 | 首页行动建议按时间、精力、日期与依赖筛选；前置完成后解锁的浏览器验收通过 |
| 明确在哪里做 | 记事本、具体业务对象及条件草稿交接；训练、旅行、采购、食谱表单验收通过 |
| 基于真实进展复盘 | 本机记录、用户补充与按需 AI 复盘；训练/采购证据和定时去重测试通过 |
| 数据与交付 | 55 项前端与 43 项 Rust 测试、Clippy、生产构建通过；打包记录及未验证边界见版本报告 |
