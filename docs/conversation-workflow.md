# 小汐：一个界面完成目标推进 · 0.12.0

从顶栏「小汐」、快捷键 `Ctrl + Shift + Space` 或全局导航「想法与目标」进入同一个对话页面。输入和对话占主要区域；右上角只保留理解图、交付清单及设置入口。

## 直接开始聊天

输入最基础的想法即可。小汐先梳理已经明确的部分，再用一两条问题引导补充。继续输入回答、纠正理解、暂停某件事或调整方向，不必切换到收集箱或编辑整份方案。

Enter 发送，Shift + Enter 换行，中文输入法选字不会发送。输入区随内容增高；查看较早消息时不强制滚动，可点「最新消息」回到底部。正在回复时仍能准备下一条输入。停止只停止等待，不应用迟到回复；已经送达服务商的请求不能撤回。失败的消息保留，点击「继续 / 重试」不会重复添加用户消息。

## 理解图：只读，随对话更新

右上角分支图标打开浮层。节点以文字、图标和颜色区分「已明确」「待确认」「尚缺信息」，层级线连接相关内容，节点附带简短依据。图中不展示模型内部推理过程。

图表没有直接编辑控件。点击节点的对话图标，将这部分引用到输入框，通过补充文字纠正。新消息尚未处理时，明确标注图表仍是上一轮理解。清单中保存的参数微调也作为明确的补充显示，并提供给后续 AI 请求。

## 最终交付清单：右侧抽屉

AI 拟定具体操作，每条列出将添加或更新的目标、事项参数、依赖和执行入口。已有事项显示修改前的参数。微调支持名称、日期、重要程度、周期、预计分钟、精力，以及明确的训练/旅行/采购/食谱条件；保存微调后会同步到后续对话。目标含义、状态与依赖关系通过对话调整，理解图保持只读。

- **执行本条**：只提交该条。需要先存在的上级目标或前置行动会显示名称；先执行依赖，或使用整批执行。
- **执行全部可执行项**：处理依赖已满足的明确条目。尚有歧义的条目及其依赖分支留在清单里，不阻塞其他明确内容。一次选择的所有更改使用同一 SQLite 事务，不留下半批结果。
- **执行记录**：成功后显示真实回执，可打开对应事项或业务入口。后续对话携带回执和当前记录，未变化的已执行项不会再次列为待执行项。
- **撤销最近一次执行**：目标关系和涉及的任务均未继续变化时可用。撤销只恢复最近一次的目标关系、任务参数、清单及回执，不抹掉用户之后修改的工作。

执行范围是保存目标、添加事项、修改已有关联事项的名称/日期/周期/重要程度，以及保存行动依赖、执行入口和条件。原事项的记事本、创建信息和完成记录受到保护。进入训练、旅行、食谱等业务页后继续生成或保存具体业务计划；本版没有在对话中订票、购买、执行终端或同步 GWorkspace。

新消息会让旧清单暂时不能执行，等对话更新清单后再继续；旧任务发生变化时也会要求重新梳理。修改失败保留清单和错误原因。重复提交使用操作编号去重。

## 执行与复盘

对话底部和首页沿用「现在先做」，根据实际完成、依赖、截止日期和时间/精力筛选行动。它使用本机规则，不额外调用 AI。点击直接进入对应记事本或业务流程。

对话的设置浮层提供当前时间与精力、小汐名字/语气/偏好、上下文预览及本机清点节奏。历史复盘和暂缓想法可以带回对话继续。系统定时清点只在应用运行时进行，不后台调用付费模型。

## 数据、兼容与验证边界

沿用 `tideplan.goals.v1`，以可选字段增加持续对话、理解图、待确认条目和执行回执。0.11.0 目标、任务及计划继续有效；首次进入时将旧小汐对话和未整理想法带入当前对话，既有原记录不删除。原任务契约和生态 contracts 未修改。

最近 160 条对话保存在目标文档中；原始输入另有想法记录。请求包含最近 40 条对话、当前理解、待执行清单、最近至多 100 条回执和目标/任务摘要，截断会标注。日历、饮食采购和项目统计可选择补充分享；任务记事本必须主动勾选。人物档案、生日、源码、项目路径及服务密钥不作为规划上下文发送。用户主动在聊天中写出的信息仍会发送。

名字与偏好沿用助手设置；API_KEY、BASE_URL、模型沿用共用配置。使用 Responses JSON Schema 结构化输出，将自然语言回复、理解图和交付清单作为一个结果校验。参考 [OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs)。不需要另配助手密钥；本对话流程不依赖旧侧栏的 function calling。

已提交消息、清单、理解图和回执纳入 JSON 备份；未发送输入只作为本机草稿，不纳入该备份。备份恢复和待写请求沿用可靠保存机制。草稿或数据库读取异常时显示错误并保留原记录。

测试使用本地 HTTP 模拟服务、隔离浏览器和明确的测试数据。多轮 UI 还使用显式的 Tauri/AI 测试替身检查上下文及操作，不代表实际模型的理解质量。没有调用真实付费 AI 或覆盖真实用户数据，跨发行版原生安装仍需实机验收。
