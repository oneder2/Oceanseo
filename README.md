# Oceanseo Personal

Oceanseo 是开源的模块化个人管理工具。本仓库只维护个人版，商业拼豆/手作产品已在独立的 `OceanseoCommercial` 仓库开发。

项目原创源码采用 [MIT 许可证](LICENSE)；字体、拼豆色卡及依赖继续遵守各自授权，详见 [第三方声明](THIRD_PARTY_NOTICES.md)。

Linux 个人版当前已本机验收至 **1.0.0**：默认只有不可删除的主工作区、主页与通用待办；可新增、重命名、删除其他工作区，并按场景添加工具。同一工具在各工作区共享资料，旧工作区数据合并并保留迁移快照。待办共享一份资料，归属选择工作区或待定。侧栏宽度和桌面窗口可调节，工作区切换菜单悬浮显示；切换和工具操作无需整页重载，避免窗口透明闪动。工具入口旁的三点菜单提供属性和删除，移除入口保留共享资料及其他工作区入口；侧栏为原生滚动条预留操作空间。拼豆统一为一个模块，窗口扩展保留系统底部面板。

个人版保留本地拼豆编辑、生活工具、账号同步、备份及自备密钥的 AI。浏览器开发预览不提供商业云端、订阅或托管 AI。旧资料库和已安装发行包不因源码清理而迁移。

```bash
npm ci
npm run dev
npm run build
npm test
npm run test:accounts-server
npm run test:sync-server
npm run cleanup
```

Linux 正式发行使用 `npm run release:linux`，安装与升级见 [1.0.0 发布说明](docs/release-1.0.0.md)，下载见 [GitHub Release](https://github.com/oneder2/Oceanseo/releases/tag/v1.0.0)。Android 独立保持 0.18.0，本次 Linux 1.0.0 的验收不代表 Android、Windows 或 macOS 已正式发布。

账号管理界面保留用于个人同步的邀请和权限管理：`npm run control:dev`，本地代理默认 4791，静态路径 `/manage/`。历史 `docs/execution/`、提案和 `output/` 中的商业记录仅供追溯。

当前域名和分离建议见 [域名与路由提案](proposals/2026-10-12-personal-commercial-domain-routing.md)；个人专用 Caddy 模板尚未应用线上，切换前必须迁移商业旧路由。

## 人物、训练与旅行（0.9.0）

- 「全局导航 → 人物档案」记录姓名、公历生日、关系、忌口、喜好、爱好、特长和训练/出行注意事项。年龄按生日计算；属相以农历新年分界，星座按常见公历区间。人物可以归档、恢复，保留既有计划关联。
- 「生活与出行 → 训练计划」录入项目、组数、每组次数/时长、开始日期、训练间隔和周期次数；可让 Agent 优化草稿，确认后生成日历训练日。逐组记录实际完成量、手动标记完成，并用 Agent 清点整个周期。复盘保存在计划中，实际记录变化时作废旧复盘。
- 「生活与出行 → 旅行规划」选择同行人物，填写起止地点、日期、人民币总预算、旅行目的、交通、住宿和偏好。常见选项可自定义输入。Agent 生成可编辑的住宿、三餐与活动草稿；费用、遗漏日程和待补充安排会提示。保存后加入日历。
- 「偏好设置」中的 AI 配置供所有 Agent 共用。旅行地图另填 **高德 Web 服务 Key**：逐站检索并确认地点后，可规划当天步行/驾车路线。地图以 OpenStreetMap 为底图，进行高德坐标转换；未定位的地点不会显示虚构坐标。国内查询优先，海外及跨城公共交通需要另行核实。

人物与生活计划纳入本机 SQLite 和 JSON 备份，密钥不包含在备份中。Agent 只在主动点击后运行，结果需检查和保存，不自动完成训练或预订旅行。详见 [业务与使用规范](docs/life-planning.md) 和 [0.9.0 验收报告](docs/release-0.9.0.md)。

## 个人拼豆工具

在工作区中添加「拼豆图纸」后，图纸编辑、作品管理与拼放进度都位于同一个模块内部。切换页面前等待保存，旧拼豆路由自动进入统一模块。画布占据页面剩余空间；顶部保留绘制工具、撤销/重做和导出，豆色、导入、填充与加边、尺寸、材料和显示改为按需打开的属性面板。宽屏面板停靠右侧，小窗口覆盖展示；开合面板保持缩放。作品支持版本、进度、库存数量（未知/缺料/够用）、完整 PNG 导出；移动端保留逐色定位与拼放功能。

画笔/橡皮整笔提交，标题、豆色、豆距同样支持撤销。导入、填充、加边、调尺寸和新建统一先对比预览、再应用。图片转换可以取消，取消后的过期结果不会覆盖当前图纸；临时预览不自动保存。选色只更新当前色，点击「用 Bxx 绘制」才进入画笔，紫色同色定位图与原色画布独立。

交互规则和模块职责见 [拼豆工作台规范](docs/bead-workbench-architecture.md)，构建与验收见 [0.8.0 发布报告](docs/release-0.8.0.md)。

## 拼豆编辑与定位（0.7.0）

- 选色后自动显示独立的「同色定位图」，用紫色位置标记当前色、灰色标记其他豆，可放大查看。主画布保持原色，定位图不参与导出；选色和吸管不再自动切换画笔，使用「用此色绘制」开始绘制。
- 「填充所有空心」只填闭合空洞，保留与画布边缘相连的空白；「区域填充」点击一处，替换上下左右相连的同色区域。两种填充均先预览、再应用，可撤销。
- 「预览轮廓加厚」按当前色向外加厚 1–8 层，包含斜角，保留原有豆和内孔。可在触边时自动扩展；超过 160×160 时拒绝操作并提示。关闭扩展时边框受画布边界限制。
- 默认显示图案与空白之间的深浅双线，帮助区分白色、浅色边缘；它是阅读辅助，不改变豆色和用量。可关闭屏幕描边，PNG 始终保留边缘辅助线。
- 实际尺寸按格数 × 豆距估算，分别显示整张画布和图案占用大小（排除外围透明留白）。支持 5 mm、2.6 mm 和 0.5–20 mm 自定义豆距；设置随图纸持久化并纳入备份，PNG 同时标注估算尺寸。品牌、底板和熨烫会影响成品大小，屏幕显示和 PNG 都不是物理 1:1 标尺。
- 增加豆色搜索、已用色筛选、当前工具说明、批量修改数量提示和预览弹窗键盘焦点管理；提高常用控件与说明文字的可读性。

## 窗口扩展（Linux 0.19.2）

点击窗口右上角的全屏按钮，或按 F11，在桌面工作区域内最大化与普通窗口之间切换，保留系统底部面板。扩展时保留工具栏和退出入口，移除窗口外边距；按 Esc 恢复普通窗口。浏览器预览在既有浏览器窗口内展开应用。桌面端有编辑弹窗时，Esc 优先关闭弹窗，再按一次退出全屏。全屏切换不会卸载当前工作区，正在编辑的图纸和内容会保留。

## 工作区与拼豆工坊（0.6.0）

0.6.0 将入口分为全局导航、任务管理、个人项目、生活饮食。全局日历和应用内日期选择器支持上一年、下一年、输入年份并按 Enter 跳转和选择月份（0100–9999 年）。

“个人项目 → 拼豆图纸”提供本地拼豆工坊：

- 导入 PNG/JPEG/WebP/BMP；原稿模式保留像素颜色，照片模式可指定 1–160 格宽高、2–48 色上限及去杂色强度。透明处留空，照片保持比例并留白，转换前后可预览。
- 图纸在可平移、缩放的画布上展示，每格标注 B 编号，配有坐标和每五格加粗网格。放大后显示编号，避免缩小时文字互相覆盖。
- 画笔、橡皮、吸管、二十步撤销/重做；支持调整尺寸（保留左上角裁切/扩展，或最近邻缩放），颜色名称与色值可编辑。
- 导出完整 PNG（含屏幕外内容、色号、坐标、用色清单和数量），桌面端可选择保存位置。导出大小随格数增长，最大图纸 160×160；图片不等于 1:1 实体打印模板。
- 当前图纸自动保存在本机并纳入 JSON 备份。当前版本保存一份图纸，替换内容先预览，可撤销；撤销历史和导入原图不随重启保留。

B01 等是应用内图纸编号，尚未内置厂商实体色卡。可在颜色名称中填入自己的品牌色号。图片处理在本地进行，不调用 AI 或上传图片。算法调研、证据及待验证的使用假设见 [拼豆图纸调研](docs/bead-pattern-research.md)。

算法回归检查：`npm test`；前端构建：`npm run build`；后端检查：在 `src-tauri` 中执行 `cargo test` 和 `cargo clippy --all-targets -- -D warnings`。

## 开发运行

先安装 Linux 原生构建依赖（Mint 22 / Ubuntu 24.04）：

```bash
sudo apt install build-essential libwebkit2gtk-4.1-dev libayatana-appindicator3-dev librsvg2-dev
```

```bash
npm install
npm run tauri dev
```

## 构建安装包

```bash
npm run tauri build
```

构建产物位于 `src-tauri/target/release/bundle/`。应用首次启动时默认注册为开机自启，并在 09:00 与 19:00 发送计划提醒；提醒时间与关键日期提前提醒范围（0–30 天）均可在“偏好设置”中调整。关闭窗口后应用会驻留系统托盘，以保证提醒继续运行。

AI 功能通过 Responses API 生成内容，使用前需要在“偏好设置”中填写可用的 API 密钥与服务地址。
